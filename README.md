# 游離 AFTERFLOW

> 每一次游移，都讓不可見的資訊有了形狀。

一件以分組放射線簇和字元塵埃呈現數位痕跡的生成式互動藝術作品。

## 本地觀看
直接用現代瀏覽器打開 `index.html`。所有樣式與腳本均已內嵌，無構建步驟，無外部相依套件，無網路請求。

- 向左移動 / 拖動：牽引字元，收束成細流
- 向右移動 / 拖動：推展字元，向外扇形散開
- 移動越快流場越強，停止後逐漸消退
- 懸停：擾動字元塵埃
- 點擊 / 輕觸：觸發放射爆散
- 滾動：卷動資訊流
- 密度滑桿：調整字元數量
- 空格：暫停 / 繼續
- F：進入 / 退出真正全螢幕，隱藏瀏覽器頂部工具列，並自動進入沉浸模式
- H：進入 / 退出沉浸模式；Esc：退出沉浸
- 留存：將當前字元場保存為 PNG
- 系統開啟減少動態效果時，初始畫面自動暫停，可手動繼續

## 發布到 GitHub Pages
1. 在 GitHub 新建一個公開倉庫，例如 `afterflow`。
2. 將本資料夾內的 `index.html`、`.nojekyll`、`README.md` 上傳到倉庫根目錄，提交到 `main` 分支。
3. 打開倉庫 **Settings → Pages**。
4. 在 **Build and deployment** 中選擇 **Deploy from a branch**，分支選擇 `main`，目錄選擇 `/ (root)`，點擊 Save。
5. 等待部署完成後，分享 Pages 頁面顯示的網址。通常形式為 `https://你的用戶名.github.io/afterflow/`。

不要將整個壓縮包作為一個檔案上傳；請先解壓後上傳其中的檔案。本作品適合桌面及移動端瀏覽器，桌面大螢幕效果最佳。

## 生成機制
15 個隨機簇中心各自生成 11 條角度相近的射線。字元按射線方向生成，帶有速度、曲率和有限壽命；透明度隨壽命漸隱。滑鼠附近的排斥力、點擊的放射粒子及滾輪的豎向流場共同改變畫面。軌跡數代表當前會話中的互動觸發次數，不是實際網路數據。

畫面中的符號是隨機生成的藝術材料，所有互動僅在本地計算，不採集或上傳觀眾數據。重置和視窗尺寸變化會重新生成隨機場。留存圖像只包含字元場及作品落款，不包含網頁操作界面。

全螢幕需由觀眾點擊「全螢幕」或按 F 主動啟用；瀏覽器不允許頁面自行進入。按 Esc 或右上角「退出觀看」返回。若內嵌預覽或行動瀏覽器限制全螢幕，請在獨立瀏覽器開啟作品。

左右移動以游標水平速度驅動局部流場。向左產生向中心線收束的牽引力，向右產生向外展開的力，並沿滑動路徑生成短壽命字元。流場有速度上限與時間衰減，暫停、離開畫布和切換視窗時會清除手勢狀態。
